# מערכת לניהול צוערים

אתר סטטי, ללא שרת וללא התקנה. כל המידע נשמר בדפדפן שבו הוא נוצר.
האפיון המלא נמצא ב־[SPEC.md](SPEC.md).

## הפעלה

פתח את `index.html` בדפדפן — זהו. אין שלב build ואין תלויות.
כדי לפתוח מהנייד, אפשר לפרסם את התיקייה ב-GitHub Pages ולגשת לכתובת.

## גיבוי — חשוב לקרוא

המידע חי ב-`localStorage` של הדפדפן שבו הוא נוצר. משמעות הדבר:

- **אין סנכרון אוטומטי בין מכשירים.** המעבר נעשה בייצוא ובייבוא יזומים.
- **ניקוי "נתוני אתרים" בדפדפן מוחק את המידע.** גבה אחת לתקופה.
- גלישה פרטית או דפדפן שחוסם אחסון — המערכת תזהיר על כך במסך ההגדרות ותעבוד
  מהזיכרון בלבד עד לסגירת הכרטיסייה.

### גוגל דרייב

*הגדרות ← גיבוי לגוגל דרייב*. מעלה לתיקייה "ניהול צוערים" בדרייב האישי, בשם
קובץ הכולל את המכשיר והמועד; הייבוא מושך לבד את הקובץ האחרון שבתיקייה.

דורש הקמה חד-פעמית של מזהה OAuth בפרויקט Google Cloud של המשתמש — ההוראות
מוטמעות במסך ההגדרות. ההרשאה היא `drive.file` בלבד, כך שהאתר רואה רק קבצים
שהוא עצמו יצר. **אין ליצור את התיקייה ידנית** — האתר לא יראה אותה ויצור אחת משלו.

שם המכשיר ומזהה ה-OAuth נשמרים תחת מפתח נפרד (`cadets-management-device`)
ואינם חלק מהגיבוי, כדי שייבוא ממכשיר אחד לא ישנה את זהותו של האחר.

## מבנה הקוד

```
index.html          שלד הדף וטעינת הסקריפטים
css/style.css       עיצוב, כולל מצב כהה ותמיכת RTL
js/util.js          עזרי תאריכים, טקסט וקבצים
js/store.js         שכבת הנתונים: CRUD, נגזרות (ספי התרעה), ייצוא/ייבוא
js/ui.js            מודאל, בונה טפסים, אישורים ורכיבי תצוגה חוזרים
js/app.js           ניתוב לפי hash ומסנן סוג הצוער הגלובלי
js/screens/         מסך לכל קובץ: home, cadets, tasks, meetings, goals, settings
```

הזרימה פשוטה: כל כתיבה ל-`store` משדרת אירוע, והמסך הנוכחי מצויר מחדש.
אין מצב תצוגה שנשמר בשני מקומות.

## ספי ההתרעה

מרוכזים ב-`THRESHOLDS` בראש `js/store.js`, מקום אחד לשנות בו:

| סף | ערך | משמעות |
|---|---|---|
| `dueSoonDays` | 7 | משימה "מתקרבת" במסך הבית |
| `staleTaskDays` | 14 | משימה פתוחה נחשבת "תקועה" ללא עדכון |
| `contactDays` | 14 | "לא נפגשנו מזמן" — לשני תפקידי הצוער |

אורך רצף ההתמדה של יעד שוטף נקבע ב-`STREAK_LENGTH` באותו קובץ: 10 ימים, 8 שבועות או 6 חודשים.
